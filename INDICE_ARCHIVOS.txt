⚡ RESUMEN DE PASOS RÁPIDOS
═══════════════════════════════════════════════════════════════════════════

1. Lee GUIA_PASO_A_PASO.md (15 minutos)
2. Instala Java JDK 11+ y MySQL (10 minutos)
3. Descarga JDBC Driver y colócalo en lib/ (5 minutos)
4. Copia archivos .java a sus carpetas correctas (5 minutos)
5. Ejecuta schema.sql en MySQL (5 minutos)
6. Edita DatabaseManager.java con tus credenciales (2 minutos)
7. Compila: javac -d bin -cp lib/* src/com/proyecto/**/*.java (1 minuto)
8. Inicia servidor: java -cp bin:lib/mysql-connector-java-8.0.33.jar com.proyecto.server.TaskServer (1 minuto)
9. Abre cliente: java -cp bin:lib/mysql-connector-java-8.0.33.jar com.proyecto.client.TaskClient (1 minuto)
10. Prueba con usuario: admin / admin123 (2 minutos)

TIEMPO TOTAL: ~45 minutos para tener todo funcionando

❓ SI TIENES PROBLEMAS
═══════════════════════════════════════════════════════════════════════════

1. "Connection refused" en cliente
   → El servidor no está ejecutándose. Verifica que iniciaste TaskServer.

2. "No suitable driver found"
   → No bajaste el JDBC Driver. Descárgalo de:
     https://dev.mysql.com/downloads/connector/j/
   → Colócalo en la carpeta lib/

3. "Access denied for user 'root'"
   → Edita DatabaseManager.java líneas 25-26 con tu usuario/contraseña MySQL

4. "Unknown database"
   → No ejecutaste schema.sql. Hazlo ahora:
     mysql -u root -p < schema.sql

Para más problemas, consulta la sección Troubleshooting en GUIA_PASO_A_PASO.md
